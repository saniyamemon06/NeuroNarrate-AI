API Documentation

Integrate NeuroNarrate's AI engine into your own products

BASE URL https://api.neuronarrate.ai

All requests require Authorization: Bearer YOUR_API_KEY header.

⚡ Endpoints

POST/v1/generateGenerate content with full emotion + tone control
POST/v1/analyzeEmotion & viral analysis on any text
POST/v1/brainstormGenerate startup ideas from a seed prompt
GET/v1/memory/:userIdRetrieve user AI memory profile
PUT/v1/memory/:userIdUpdate user personality twin data
GET/v1/analytics/:userIdFull content analytics for a user
